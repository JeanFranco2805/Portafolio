Sobre mí

Backend Engineer con sistemas
reales en producción

Soy Backend Engineer con más de 4 años de experiencia construyendo sistemas para clientes reales. Me especializo en Java y Spring Boot — Security, Data, Web y Cloud — desarrollando APIs REST, módulos de autenticación y backends escalables pensados para mantenerse en producción.

He diseñado, desarrollado y desplegado en AWS un sistema de gestión y monitoreo laboral con integración de dispositivos físicos para captura de datos en tiempo real (L&H Distribuciones S.A.S). También implementé el backend completo de una plataforma clínica con gestión de citas, historiales y control de acceso seguro, y una plataforma académica institucional con administración de horarios y usuarios.

Trabajo con PostgreSQL, MySQL, Oracle y MongoDB, Docker, testing con JUnit y Mockito, y aplico patrones de arquitectura y diseño desde el inicio de cada proyecto. Mi prioridad es entregar código limpio, seguro y mantenible.
